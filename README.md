# 수학정원 · siyoon-garden

초등학교 2학년 학생이 태블릿과 PC에서 사용하는 수학 학습 웹앱입니다.

## 기능

- 덧셈, 뺄셈, 구구단, 시계 읽기
- 기초 / 도전 난이도와 한 번에 5문제 학습
- 오답 풀이, 다시 풀기, 별과 학습 기록
- 브라우저 localStorage에 기록 저장 (기기 간 동기화 없음)

## 파일 구조

`dist/index.html`, `dist/style.css`, `dist/app.js`가 서비스에 필요한 정적 파일의 전부입니다. 별도의 빌드, Node 서버, 데이터베이스가 필요하지 않습니다. 글꼴은 Google Fonts를 사용하며 연결할 수 없으면 시스템 글꼴을 사용합니다.

## 로컬 실행

원하는 정적 HTTP 서버에서 `dist` 폴더를 서비스합니다. HTML 파일을 직접 여는 대신 HTTP 주소로 접속하면 배포 환경과 같은 방식으로 확인할 수 있습니다.

## 서버 배포

### Render

저장소 루트의 `render.yaml`을 Render Blueprint로 연결하면 정적 사이트를 생성할 수 있습니다. GitHub에 새 커밋을 올리면 자동 배포합니다.

수동으로 생성할 때는 Render에서 **New → Static Site**를 선택하고 GitHub 저장소를 연결한 뒤 다음 값을 입력합니다.

- Build Command: `echo "Static files are ready"`
- Publish Directory: `dist`
- 별도 환경 변수나 데이터베이스: 필요 없음

Render에 게시한 사이트는 URL을 아는 사람이 접속할 수 있습니다. 현재 앱에는 별도 사용자 로그인 기능이 없습니다.

### 기타 웹 서버

정적 웹 호스팅의 게시 디렉터리를 `dist`로 설정합니다. 직접 운영하는 웹 서버에서는 `dist` 안의 세 파일을 웹 루트에 복사합니다. 별도의 빌드 명령은 없습니다.

`.openai/hosting.json`은 기존 Sites 배포 연결 정보입니다. 일반 웹 서버는 이 파일을 사용하지 않습니다. 저장소에는 비밀번호나 배포 토큰을 넣지 않습니다.

새 도메인으로 이전하면 기존 도메인의 브라우저 학습 기록은 자동으로 옮겨지지 않습니다.
